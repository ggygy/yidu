# 09: 可点击低保真原型(快捷窗 + 主窗口)

Type: prototype
Status: resolved
Blocked by: 05

## Question

用假数据、按已定案技术栈(React + Tauri 壳)做可点击低保真原型,验证静态视觉稿(`visual/reader-ui.pen` 四屏 A-D)定不下来的**交互**:① 快捷翻译浮窗——唤出/隐藏、pin 置顶、粘贴即译、上下对照切换、存入文章库,以及窗口行为(失焦后隐藏还是保留、位置与尺寸记忆、多显示器);② 主窗口阅读界面——双语对照↔分栏切换、折叠为纯译文、点词弹卡(生词本入口,含释义+原文例句)、术语库入口、文章库列表页。原型是讨论"交互该怎么定"的靶子,不是实现。

## Resolution (2026-11-14)

原型建成(`proto/`,npm run tauri dev,双窗),browser-use + osascript 自动化测试通过并修 3 bug(详见 proto/README.md)。用户按推荐定案四个交互默认值:

1. **重启后快捷窗不自动显示**——实现时禁用 window-state 插件对可见性的恢复(位置/尺寸仍记忆),首次由 tray 或快捷键唤出。
2. **默认全局快捷键 ⌥Space → ⌥T**,且在设置页可配置(⌥Space 与输入法切换冲突,实测偶发丢键)。
3. **失焦默认不隐藏**(保留窗口);失焦隐藏作为可选开关,与 pin 互斥。
4. **pin 默认开**(浮窗常驻置顶是产品主体心智)。

另:快捷窗「显示原文(对照)」按钮为超出原 roadmap 的补强,正式进 P0 spec;视觉稿 v3(reader-ui-v3.pen)定为主窗+快捷窗的视觉基准,原型待同步。
