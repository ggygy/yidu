```bash
npm install

```

主窗口自动打开;快捷窗默认隐藏,按 **⌥T** 唤出(2026-11-14 定案:默认 ⌥T,⌥Space 与输入法冲突弃用;设置页可配置——原型里未做改键 UI)。

## v3 结构对照

| 视觉稿屏 | 原型落点 |
|---|---|
| G1 沉浸阅读 | 无侧栏无工具栏:顶栏(文章库 ⌘K / 标题 / 设置)+ 底部悬浮胶囊(三视图/术语/生词/Provider/重译)+ 顶部发丝进度条 |
| G1b 点词生词卡 | 点英文词 → 查询中 ··· → 释义(已知词「有道词典(免费)」/未知词延迟后「模型兜底」,演示查词回落链)+ 例句 + 加入生词本 |
| G2 库滑出层 | ⌘K 或点「文章库」→ 遮罩 + 左浮面板(搜索/列表/置顶标/底部术语库·生词本入口) |
| G3 全屏新建 | ⌘N 或库内「新建」→ 取消 + 书写区 + 拖放区 + 底部胶囊(字数/方向/导入/翻译 ⌘↩) |
| H / H2 快捷窗 | 单行头部(红绿灯+⌥T+pin/主窗/关)+ 去框控制行(方向/⚡/Provider chip 可轮换)+ 输入块(键帽)+ 悬浮操作胶囊(复制/对照/存入文章库) |
| S 设置滑出层 | 主窗 ⌙ 设置 → 右滑出:Provider 预设四件套/连通测试/翻译(含**单词查词:免费词典→模型兜底**)/快捷键与浮窗三默认/深色外观/本地用量 |

## 试玩清单

**主窗口**
1. ⌘K 开关库滑出层;搜索过滤;点条目关层
2. 胶囊切三视图(双语对照/分栏/纯译文);纯译文「⌄ 原文」展开单块
3. 点英文词 → 生词卡(注意来源标签:词典命中 vs 模型兜底)→ 加入生词本看胶囊计数
4. 设置滑出层:切「深色外观」→ 全页变暗(快捷窗重开后跟随);Provider 预设切换
5. ⌘N 全屏新建 → 粘贴/拖入 .md → 翻译 ⌘↩(罐头流式)
6. 术语块(左侧竖条 + hydration→水合 chip);块 4 永远停在 streaming 展示态

**快捷窗(⌥T 唤出)**
1. 「载入演示 ⚡」→ 粘贴即译 + 流式逐字上屏 + markdown 渲染
2. 胶囊「对照」开/关 → 上下对照;「复制」;「存入文章库」→ 主窗库顶上多一条
3. Provider chip 点击轮换(GLM → DeepSeek → Ollama)
4. pin 默认开;底部「失焦隐藏」实验开关(与 pin 互斥,自动关另一个)
5. ⌥T 反复按 → 显隐切换
