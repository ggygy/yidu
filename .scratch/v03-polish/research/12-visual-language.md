# 12 · 整体视觉语言定案:macOS 原生

> 日期:2026-11-17 · 工单 [12](../issues/12-visual-language.md) · 原型:[proto-visual/index.html](../proto-visual/index.html)(`?variant=C`,← → 切方向、T 亮暗、L 侧栏、I 检查器)
> 输入:工单 11 差距审计([11-visual-audit.md](11-visual-audit.md));三个方向 A(v4 精修)/ B(指令条式)/ C(macOS 原生)并排比较后用户选 C。

## 用户决议

| 问题 | 决定 |
|---|---|
| 整体方向 | **C · macOS 原生**:系统材质(半透明模糊)、SF 字体、统一工具栏 + 分段控件、弹出按钮、系统设置式分组列表 |
| 亮/暗 | **跟随系统**,亮暗同等打磨,可手动覆盖 |
| 译文正文字体 | **无衬线**(SF / 苹方 中粗 500),弃 Source Serif 4 与宋体回落 |
| 文章库 | **原生侧栏,默认收起**(工具栏 ☰ / ⌘K 展开并聚焦搜索) |
| 检查器(进度 / 本次指标 / 术语命中) | **默认收起**(ⓘ / ⌘I);收起时工具栏常驻精简进度条 + 「块 n/m · 首字 x.xs」 |
| 强调色 | **跟随系统强调色**(由 Rust 读 `NSColor.controlAccentColor` 注入 `--accent`,见工单 13;CSS `AccentColor` 在 WKWebView 不可靠),回退 `#0a7aff` / `#0a84ff` |

由 C 方向直接推出(原型已呈现,spec 撰写时一并确认):设置改为**独立「系统设置」式窗口**(⌘,,左侧 4 个分区:模型 / 翻译 / 快捷窗 / 用量),不再是主窗右滑出层;快捷窗「对照」按钮升级为工具栏分段控件 **原文 | 译文 | 对照**;方向与模型改为**弹出按钮**;主窗底部悬浮胶囊**取消**,视图切换上移到工具栏分段控件。

## 设计 token(v0.3 基准)

### 字体

| token | 值 | 用途 |
|---|---|---|
| `--f-ui` | `-apple-system, "SF Pro Text", "PingFang SC", sans-serif` | 全部界面 + 译文正文 |
| `--f-mono` | `"SF Mono", "JetBrains Mono", Menlo, monospace` | 代码、行内码、URL 预览 |
| 字重 | 界面 400 / 强调 600 / 译文正文 **500** / 原文 400 / 标题 700 | 只用系统字体,无需打包西文字体文件 |

### 字号阶梯(pt)

| 级 | 值 | 用途 |
|---|---|---|
| caption | **11**(最小,不再出现 9.5 / 10.5) | 侧栏分组标题、元信息、状态栏指标 |
| footnote | 12 | 分段控件、弹出按钮、设置脚注 |
| body | 13 | 界面正文(macOS 默认) |
| source | 14.5 | 主窗对照视图原文 |
| quick | 15 | 快捷窗译文 |
| reading | 17 | 主窗译文 |
| title-2 | 22 | 分栏视图标题 |
| title-1 | 28 | 文章标题(左对齐、700) |

行高:正文 1.7(原文)/ 1.75(快捷窗)/ 1.85(主窗译文);⌘+ / ⌘− 以 reading 与 quick 为基准整体缩放(细节归工单 09)。

### 颜色(语义 token,对齐 macOS label 体系)

| token | 亮 | 暗 | 对比度要求 |
|---|---|---|---|
| `--t1` label | `#1d1d1f` | `#f5f5f7` | 正文 ≥ 7:1 |
| `--t2` secondaryLabel | `#4c4c52` | `#c7c7cc` | 原文、次要信息 ≥ 4.5:1(审计中原文 2.32:1 由此修正) |
| `--t3` tertiaryLabel | `#6e6e73` | `#98989f` | 元信息 ≥ 4.5:1 |
| `--line` separator | `rgba(0,0,0,.10)` | `rgba(255,255,255,.10)` | 0.5px 发丝线 |
| `--bgdoc` 文档区 | `#ffffff` | `#1e1e1e` | 阅读区实底,不透明 |
| `--group` 分组底 | `#ffffff`(窗底 `#f2f2f7`) | `#2c2c2e` | 设置分组列表 |
| `--mat` 材质 | NSVisualEffectView(CSS 回退 `rgba(246,246,248,.78)` + blur 30px) | 回退 `rgba(40,40,44,.72)` | 工具栏、侧栏、检查器、快捷窗外框 |
| `--accent` | 系统强调色(Rust 注入)→ `#0a7aff` | 系统强调色 → `#0a84ff` | accent 底白字;**禁用态不再用半透明 accent**,改灰底 `--t3` 字 |
| `--ok` | `#28a745` | `#32d74b` | 连通 / 成功 |
| 代码块 | 文档区内 `rgba(120,120,128,.12)` 底,不再用固定黑底 | 同 | 随亮暗 |

规则:同一画面只用材质 + 文档实底两种面,不出现第三种背景色(修审计「顶栏与正文色带」)。

### 形状与间距

- 4pt 网格;窗口圆角 12(系统),分组卡 10,控件 6,行内码 4。
- 工具栏高 52(含红绿灯,内容与红绿灯中线对齐,左让位 ≥ 70pt);设置行最小高 38;快捷窗状态栏 34。
- 阴影交给系统窗口;页内不加卡片阴影。

### 控件

分段控件(视图/原文译文对照)、弹出按钮(方向、模型、服务商)、开关(用强调色)、系统风格按钮(主操作 accent 实底,次操作材质底)。不再有自绘 chip 堆、快捷键提示 chip、外凸胶囊按钮。

### 信息密度与文案

- 快捷键只出现在菜单、tooltip、设置页,**界面常驻区不放键位提示**。
- 删除所有调试/实验文案(「演示 ⚡」「实验开关…」「(P1 识别)」)。
- 指标:快捷窗状态栏一行(首字 · 输出 tok · 速度);主窗收起时工具栏精简一行,展开检查器看全量(首字/耗时/输入/输出/速度/成本)。具体字段与口径归工单 06。

### 动效

侧栏/检查器展开收起 200ms ease-out;流式上屏 = 当前块末尾强调色闪烁光标(1s steps);不加弹跳与淡入。

## 关键屏(原型 C 已呈现)

1. 快捷窗:统一工具栏(红绿灯 + 分段控件 原文|译文|对照 + 置顶/复制),弹出按钮行(方向「自动(英语)→ 中文」、模型),源文摘要框,文档实底译文区,状态栏(指标 + 复制 + 存入文章库)。
2. 主窗:统一工具栏(分段控件 对照|分栏|译文、标题、精简进度、☰ ⓘ ⚙),侧栏默认收起,检查器默认收起。
3. 设置:独立窗口,左侧带彩色图标的 4 分区,右侧分组列表 + 脚注式连通结果与请求 URL。

- WKWebView 对 CSS `AccentColor` / `prefers-color-scheme` 的支持与实时跟随。
- 统一工具栏 + 红绿灯位置(`titleBarStyle: Overlay` + `trafficLightPosition`)。
