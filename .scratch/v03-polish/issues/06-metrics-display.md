# 06: 翻译指标展示设计

Type: prototype
Status: resolved
Assignee: wangjunzhou (claimed 2026-11-17)
Blocked by: 05, 12

## Question

每次翻译向用户展示哪些指标(TTFT、首块、总耗时、in/out tokens、tok/s、估算成本、模型名)、放在哪里(快捷窗底栏可展开的一行、主窗胶囊/文章元信息、设置页用量页)、默认显隐;`usage_log` 需增加哪些列(如 `ttft_ms`);以及让流式「可感知」的视觉(当前块光标/逐字淡入/批进度),出可点原型供用户反应。

## Answer

(2026-11-17)三方案原型([proto-metrics/index.html](../proto-metrics/index.html):A 一行摘要 + ⓘ / B 实时阶段计时器 / C 分级 + 与平时比较)比较后定案:

1. **进行中 = B 实时阶段**:快捷窗状态栏与主窗工具栏显示彩色呼吸点 + 阶段(连接 / 思考 / 生成)+ 运行计时 +(生成阶段)实时 tok/s;当前流式块浅强调底 + 末尾闪烁光标,其余待译块显示「还有 N 块待译」。
2. **结束后 = A 一行摘要 + ⓘ 明细**:状态栏一行「首字 x.xs · 总耗时 · 输出 tok ⓘ」;点 ⓘ 弹出明细——连接/思考/生成分段时间条、首字(TTFT)、首块完成、输入/输出(含思考 tok)、生成速度、估算成本、模型·块数·批数;主窗检查器展示同一份明细(进行中显示实时数据)。
3. **思考**:开着思考时显示「思考中… N 字 · Ts」进度行,首个正文到达后收成「▸ 已思考 …」可点开看末尾约 200 字;明细中提示思考占比与「关闭思考可加快首字」。思考文本绝不进译文。
4. **设置「用量」页**:月汇总(请求 / token / 估算成本)+ 各模型首字中位数(最近 20 次)+ 最近 20 次请求表(时间 / 模型 / 首字 / 总耗时 / 输入输出 / 思考 tok),首字按 <1s 快 · 1–3s 一般 · >3s 慢 分级着色。
5. **口径与落库**(沿用工单 05):TTFT = 首个正文 token − 请求发出;首块 = 首个完整块;速度 = 正文输出 tok /(结束 − 首正文 token);`usage_log` 增 `ttft_ms, first_block_ms, first_byte_ms, reasoning_tokens, batch_blocks, batch_chars`;前端需新增 `usage` / `thinking` 事件处理(修 A 类「Usage 事件未处理」)。
