## Question

⌥T 应有怎样的唤出语义才「每次都能打开」:已聚焦→隐藏、否则 show + unminimize + 激活 App + focus;App 激活策略(保留 Dock 图标 vs Accessory 菜单栏应用);跨 Space、全屏应用上方的行为;离屏位置(拔显示器)如何夹回;热键注册失败/冲突的提示方式与改键校验(必须含修饰键);失焦隐藏与 pin 的交互是否保留。

## Answer

(2026-11-17 grilling,用户全部采纳推荐;依赖 01 已解除,实测并入 01 验收)

1. **⌥T 语义**:快捷窗在前台且有焦点 → 隐藏;否则(隐藏 / 被遮挡 / 在别的桌面 / 最小化)→ 移到当前桌面、取消最小化、激活应用、置前并聚焦输入框。不再只看 `is_visible()`。
2. **Dock 图标**:只开快捷窗时为纯菜单栏应用(Accessory,无 Dock 图标,唤出不抢切桌面);主窗或设置窗打开时切为 Regular 显示 Dock 图标,全部关闭后切回。
3. **出现位置**:鼠标所在显示器 + 当前桌面(含全屏应用之上,`canJoinAllSpaces` + `fullScreenAuxiliary` 类行为);位置按该屏记忆的**相对位置**,越界即夹回可见区域;拔显示器不会「打开了但看不见」。与工单 09 的自动长高、下方不够就上移协同。
4. **关闭即隐藏**:红灯 / ⌘W 一律 hide 不销毁(主窗、设置窗同理,见 A 类必修)。
5. **失焦自动隐藏**:保留为设置「快捷窗」分区的正式选项,默认关,与置顶互斥;唤出后 300ms 内不触发,防刚出现就被藏;删除界面上的「实验开关」文案。
6. **热键冲突**:注册失败 → 发系统通知「⌥T 被占用,点此改键」+ 菜单栏图标加感叹号,菜单首项「打开快捷窗」始终可用;设置里该行标红。
7. **改键校验**:必须含 ⌘ / ⌥ / ⌃ 之一;录入后当场试注册,失败保留旧键并提示「已被占用」;旧键未注册时也能改(修 `unregister?` 失败导致改不了的缺陷)。
8. **剪贴板预填**:保持现状——仅当剪贴板为上次唤出后新复制的文本才预填,否则保留上次输入与结果。

验收(并入工单 01 实机):连续 50 次 ⌥T 在「被遮挡 / 其他桌面 / 全屏应用 / 关闭后 / 拔显示器」各场景均一次唤到前台并聚焦。
