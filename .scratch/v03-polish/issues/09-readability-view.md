# 09: 译文可读性与视图自适应

Type: prototype
Status: resolved
Assignee: wangjunzhou (claimed 2026-11-17)
Blocked by: 12

## Question

译文怎样才「好读且不用手动拖窗」:快捷窗与主窗是否各自独立的字号/行高、正文用无衬线还是补全衬线字重、⌘+/⌘− 即时缩放;快捷窗高度是否随内容自动增长(上限屏高)、有结果后输入框是否折叠;对照模式在窄窗下改上下排;md 渲染样式(标题、列表、表格、代码、引用)对齐 GitHub/Typora。出可点原型(亮暗两套)供用户反应。

## Answer

(2026-11-17)三方案原型([proto-reading/index.html](../proto-reading/index.html):A 自动长高 / B 固定尺寸 + Aa / C 两档吸附)比较后定案,用户全部采纳推荐:

1. **快捷窗 = 自动长高**:宽度固定(默认 440,记忆用户拖过的宽度),高度随内容(含流式逐块)增长,动画 220ms ease-out,上限 **85% 屏高**后内部滚动;清空时缩回紧凑态。
2. **长高方向**:默认向下;下方空间不够时整体上移,窗口始终完整可见(按当前所在显示器计算)。
3. **手动拖动**:本次会话内用户拖了高度即暂停自动,下次唤出或新翻译恢复自动。
4. **输入区折叠**:有结果后输入框收成一行「原文 · …」,点击展开编辑。
5. **视图**:工具栏分段控件 译文 | 对照 | 原文;快捷窗窄宽下「对照」= 每块上原文(次要色 13.5px)下译文,块间虚线分隔。
6. **字号**:⌘+ / ⌘− / ⌘0 即时缩放(0.8~1.5 倍),快捷窗与主窗各自记忆;阅读外观设置**精简为「字号 + 紧凑/标准/宽松」**,删除主题/字体/块距/宽度/强调色等选项(由工单 12 系统化视觉接管)。
7. **md 渲染样式**:以原型共用 `.md` 样式为基准(用户确认达到 GitHub/Typora 标准):正文无衬线 500、15px/1.75;h2 1.3em 带发丝下划线、h3 1.1em;嵌套列表 1.5em 缩进、次要色标记;表格发丝边框 + 表头底色、窄宽横向滚动;引用左竖线次要色;代码块随亮暗的浅底 + SF Mono;链接强调色无下划线 hover 下划线。
