# 07: 模型配置交互重做

Status: resolved
Assignee: wangjunzhou (claimed 2026-11-17)

## Question

设置页 Provider 区如何重做:显式「保存配置」vs 自动保存/脏状态提示;「测试」使用表单当前值而非已存行;模型选择从自由文本改为 `GET /models` / Ollama `/api/tags` 下拉 + 手填兜底;最终请求 URL 预览;测试结果与错误分类文案(key 错/模型错/URL 错/网络)的位置;点预设 chip 不得在无 key 时激活;快捷窗 chip 是否可直接切模型。出可点原型供用户反应。

## Answer

(2026-11-17)三方案原型([proto-config/index.html](../proto-config/index.html):A 单页分组 / B 列表+详情 / C 向导)比较后定案,用户全部采纳推荐:

1. **结构 = B 列表 + 详情**(设置窗口「模型」分区):左列列出全部服务商,每项显示连通状态点(绿已连通/红失败/灰未测试)、当前模型与「使用中」徽标;右侧详情:地址、密钥、模型、思考(默认关)、最终请求 URL 预览、测试结果、测试 / 设为使用中 / 删除。
2. **自动保存**:去掉「保存配置」按钮,字段改完即存并短暂提示「已自动保存」;地址/密钥/模型任一变更即把该服务商标为「未测试」。
3. **测试用当前填写值**(不再读已存行);结果分类文案:缺少密钥 / 密钥无效(401)/ 模型不存在(404)/ 无法连接(网络、代理)/ 成功(延迟 + 上下文上限)。
4. **模型 = 下拉**,点开即拉取 `GET /models`(Ollama `/api/tags`),保留手填兜底。
5. **激活门槛**:「设为使用中」前自动跑一次测试,失败不切换并显示原因;**点预设不再立即激活**。快捷窗菜单里未通过的服务商置灰。
6. **快捷窗模型弹出菜单**:每个服务商一行(其当前模型)+ 延迟或「连接失败/未配置」,末项「管理模型… ⌘,」;换模型去设置。
7. **添加 / 首启**:点「＋ 添加」弹预设面板(DeepSeek/GLM/OpenAI/Ollama/自定义),选后列表新增并聚焦密钥框;粘贴密钥即自动测试 + 拉取模型;首次启动无服务商时的空状态就是这块预设面板(地图雾区「首启 onboarding」由此毕业)。
8. **密钥显示**:已存显示「已存于钥匙串 ····9a1e」+「更改…」,点更改才变输入框;前端永不拿完整密钥。

附带(来自代码诊断,进 spec 必修):Ollama `num_ctx` 默认改回 8192;测试命令改为接收表单值;删除 `PRESETS` 硬编码模型清单对 datalist 的依赖。
