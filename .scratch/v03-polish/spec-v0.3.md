## 2. 七大痛点:根因 · 方案 · 验收

### 2.1 自动方向识别

**根因**:`detectDir`(`src/languages.ts:53-66`)单个假名/谚文/西里尔字符即定语种;代码、URL、标识符计入拉丁字母,中文技术文被判成英文;纯汉字日文判中文;法语重音规则先查,德/西与英文借词(café)被判法语;错误源语写进 prompt 误导模型;目标语写死。实测(v0.2.3 函数级):中文+代码块 → `en2zh` ✗、`東京駅` → `zh2en` ✗、含 café 英文 → `fr2zh`。

**方案**:
1. 识别器换成前端零依赖**启发式 v2**(`detectLang(text) → {lang, conf}`):先剔除代码块/行内码/HTML/URL/路径/标识符 → 加权脚本占比 → 假名比例(引号内不计)+ 日本专用汉字 + 简繁混用判中日 → 拉丁语按功能词计分、重音封顶。参考实现 `research/lang-detect-bench/heuristic_v2.mjs`。
2. **目标语 = 母语 + 第二语言**(设置新增,默认中文 / 英语):源为母语 → 译第二语言,否则 → 译母语。
3. **整篇一个方向**;已是目标语的块由模型原样保留。
4. **低置信(conf < 0.6)照发**:方向弹出按钮显示「自动 · 中 → EN ?」;纯汉字、≤ 8 字、无中文虚词无日本信号时 conf 降为 0.5,菜单首项「可能是日文 → 日 → 中 重译」。
5. **手改只管这一次**:弹出按钮改方向 = 以该方向重译当前文本,仍保持自动;要固定方向须显式选具体方向退出自动。
6. **Prompt**:conf ≥ 0.6 写「{from} → {to}」;conf < 0.6 只写「translate into {to}」(新增未知源编码 `?2{to}`,`prompt.rs` 支持)。
7. **双窗共享**一个 `prefs.direction`,任一侧切换经 `prefs-changed` 同步。

**验收**:106 条标注样本(`research/lang-detect-bench/`)目标方向 ≥ 95%、源语言 ≥ 90%;「?」徽标与「可能是日文」入口可见;改向重译后仍为自动;两窗方向切换即时同步。已知残留:无日本专用字的纯汉字日文(株式会社)仍判中文。
— 工单 [02](issues/02-lang-detect-research.md)、[03](issues/03-auto-direction-rules.md)

### 2.2 md 结构保真与渲染

**根因**:`blocks.rs` 按顶层列表**项**拆块,前端逐块独立渲染 → 一个列表变 N 个单项列表,松散/任务/编号续接走样;`---`、脚注、链接定义被丢;引用标成段落;表格无校验;HTML 与缩进文本当 code 不译;纯文本单换行被合并、行首 `#`/`1.`/`>` 被当 md;源文含 `</t>` 会破坏协议;校验只看 id、URL 集合、``` 计数;temperature 1.0。原型实测(不经模型):现行逐块渲染结构一致 4/10,模拟损伤检出 1/10。

**方案**:
1. **块模型**:所有顶层节点都成块、不丢弃;**列表 / 引用 / 表格整体一块**翻译,超约 1200 字才按顶层项拆,拆开项带 `group`,渲染合回一个列表;块间保留原文分隔文本(拼回即原结构)。
2. **直通不译**:代码(围栏/缩进)、HTML 块(按 html 渲染,不再伪装 code)、hr、脚注定义、引用式链接定义。
3. **渲染**:同 group 合并为一个 md 片段渲染;对照视图按块配对(整列表对整列表)。
4. **结构签名校验**(取代仅 URL + ``` 计数):标题级、列表(有序/起始号/项数/层级/松散/任务)、表格(列 × 行)、代码块数、行内码集合、URL 集合、引用/hr/HTML/脚注计数。不一致 → 带差异说明**自动重译该块一次** → 仍不一致保留译文、标「格式可能有误」+ 一键重译。
5. **纯文本粘贴**:按 md 语法密度自动判定;纯文本时段内单换行保留为硬换行、行首 md 记号转义;输入区「Markdown / 纯文本」小开关可改判。
6. **协议转义**:源文 `<s` `</s` `<t` `</t` 发送前转义为 `&lt;…`,回收后还原。
7. **temperature** 默认 0.3,服务商详情可覆盖(见 §6 待定)。
8. **渲染样式**:以 `proto-reading/index.html` 的 `.md` 为基准(用户确认达 GitHub/Typora 水平):正文系统无衬线 500、15px/1.75;h2 1.3em 发丝下划线;嵌套列表 1.5em 缩进;表格发丝边框 + 表头底色、窄宽横向滚动;引用左竖线;代码块随亮暗浅底 + SF Mono;链接强调色。

**验收**:`proto-md/roundtrip.mjs` 样例集拼回结构一致 10/10、损伤集检出 10/10(移植为 Rust 单测);真实模型下结构签名失败率记录为指标(目标 < 5%,未实测)。
— 工单 [04](issues/04-md-fidelity.md)、[09](issues/09-readability-view.md)

### 2.3 模型配置

**根因**:点预设 chip 即保存并激活(无 key 也激活,翻译随即失败);单独「保存配置」按钮且切 chip 静默丢弃编辑;「测试」读已存行,未保存的 key/URL/模型测不到;模型是硬编码 datalist,未调用 `/models`、`/api/tags`;无最终 URL 预览;测试结果只有 `✓ N ms` 或原始 HTTP 体,挤在 Key 行里。

**方案**(设置窗「模型」分区,原型 `proto-config/index.html` 方案 B):
1. **服务商列表 + 详情**:左列全部服务商,每项连通状态点(绿已连通 / 红失败 / 灰未测试)、当前模型、「使用中」徽标;右侧详情:地址、密钥、模型、思考控制、temperature、最终请求 URL 预览、测试结果、测试 / 设为使用中 / 删除。
2. **自动保存**:无保存按钮;地址/密钥/模型任一变更即标「未测试」。
3. **测试用表单当前值**;错误分类:缺少密钥 / 密钥无效(401)/ 模型不存在(404)/ 无法连接(网络、代理)/ 成功(延迟 + 上下文上限)。
4. **模型下拉**:点开即拉取 `GET /models`(Ollama `/api/tags`),保留手填。
5. **激活门槛**:设为使用中前自动测试,失败不切换并显示原因;点预设不再立即激活。
6. **快捷窗模型菜单**:每个服务商一行(其当前模型)+ 延迟或「连接失败 / 未配置」,失败置灰;末项「管理模型… ⌘,」。
7. **添加与首启**:「＋」弹预设面板(DeepSeek / GLM / OpenAI / Ollama / 自定义),选后新增并聚焦密钥框,粘贴即自动测试 + 拉取模型;首启无服务商时空状态即此面板。
8. **密钥**:已存显示「已存于钥匙串 ····9a1e」+「更改…」;前端永不拿完整密钥。
9. **思考控制**(来自 §2.6):预设按 host 自动;自定义服务商(如 ada)提供「自动 / 不注入 / DeepSeek 式 / Qwen 式 / 自定义 JSON」下拉。

**验收**:无 key 预设不可能成为使用中;未保存的修改可直接测试;四类错误各有明确文案;拉取模型 ≤ 1 次点击。
— 工单 [07](issues/07-provider-config-redo.md)

### 2.4 快捷窗唤出可靠性

**根因**:关闭即销毁(§1);`toggle_quick` 只看 `is_visible()`,被遮挡/另一桌面/最小化时反而隐藏;未激活应用即 `set_focus`,窗口可能无焦点并被失焦隐藏立刻藏起;注册失败不可见;改键在旧键未注册时失败;window-state 恢复到已拔掉显示器的位置(打开了但看不见)。

**方案**:
1. **⌥T**:前台且有焦点 → 隐藏;否则移到当前桌面、取消最小化、激活应用、置前并聚焦输入框。
2. **Dock**:仅快捷窗时为 Accessory(无 Dock 图标,唤出不切桌面);主窗或设置窗打开时切 Regular,全部关闭后切回。
3. **位置**:鼠标所在显示器 + 当前桌面(含全屏应用之上);按该屏记忆的相对位置,越界夹回;与 §2.5 自动长高协同。
4. **失焦自动隐藏**:设置「快捷窗」分区正式选项,默认关,与置顶互斥;唤出后 300ms 内不触发。
5. **热键冲突**:注册失败 → 系统通知「⌥T 被占用,点此改键」+ 菜单栏图标感叹号,菜单首项「打开快捷窗」始终可用;设置该行标红。
6. **改键**:必须含 ⌘/⌥/⌃;录入后当场试注册,失败保留旧键并提示。
7. **剪贴板预填**:仅当剪贴板为上次唤出后新复制的文本。

**验收**:被遮挡 / 其他桌面 / 全屏应用 / 关闭后 / 拔显示器 五场景各 50 次 ⌥T,全部一次唤到前台并聚焦(基线未测,见 §6)。
— 工单 [08](issues/08-quick-window-summon.md)

### 2.5 可读性与视图自适应

**根因**:译文默认衬线且仅 600 字重(粗衬线 + 宋体回落);快捷窗固定 420×660,输入框固定 76px 不收起,底部胶囊 + 提示行吃掉 74px;对照在 420 宽下两栏各约 190px;无 ⌘± 与自适应高度;对照原文 12.5px、对比度 2.32:1;最小字号 9.5px。

**方案**(原型 `proto-reading/index.html` 方案 A):
1. **快捷窗自动长高**:宽固定(默认 440,记忆用户拖过的宽度);高随内容(含流式)增长,220ms ease-out,上限 85% 屏高后内部滚动;清空缩回。
2. 默认向下长,下方不够则整体上移,始终完整可见。
3. 用户手拖高度 → 本次会话暂停自动,下次唤出/新翻译恢复。
4. 有结果后输入框收成一行「原文 · …」,点击展开。
5. 分段控件 **译文 | 对照 | 原文**;窄宽对照 = 每块上原文(次要色 13.5px)下译文。主窗分栏为左右两栏。
6. **⌘+ / ⌘− / ⌘0**(0.8–1.5 倍),快捷窗与主窗各自记忆;阅读外观设置精简为「字号 + 紧凑 / 标准 / 宽松」,删除主题 / 字体 / 块距 / 宽度 / 强调色(视觉由 §2.7 接管)。

**验收**:最小字号 11pt;次要文字对比度 ≥ 4.5:1;短译文窗口不出现大片空白、长译文不需手动拖窗;对照模式下单栏宽 ≥ 360px。
— 工单 [09](issues/09-readability-view.md)、[11](issues/11-visual-audit.md)

### 2.6 流式感知与翻译指标

**根因**:三个默认预设(deepseek-flash / glm-4.5-flash / Ollama qwen3)可能默认开思考,`sse.rs` 只读 `delta.content`、丢弃 `reasoning_content` → 长时间空白;首批即 ≤10 块 / 2000 字;SSE 丢正文与主窗丢事件(§1)让短文"一次性出现";`usage_log.latency_ms` 只有总耗时,无 TTFT;`usage` 事件无人处理。基线(ada 历史 21 次请求,单请求总耗时):最小 0.66s / 中位 **4.5s** / 最大 **48.0s**;completion 16,801 tok ≈ prompt 11,238 的 1.5 倍,疑似思考 token 计入输出(推断)。

**方案**:
1. **关思考**:按 host 白名单注入——DeepSeek / 智谱 `"thinking":{"type":"disabled"}`、百炼 `"enable_thinking":false`、OpenAI 推理模型 `"reasoning_effort":"none"`(不认则 `"low"`)、Ollama `"think":false`(gpt-oss 用 `"low"`);其他 host 不注入,由 §2.3 思考控制下拉决定。注入后 400 且错误提及该字段 → 去字段重试一次并记为「不支持」。
2. **思考关不掉时**:解析 `reasoning_content` / `reasoning` / Ollama `message.thinking` 为独立 `thinking` 事件(不进 `</t>` 状态机,≥100ms 节流);UI 显示「思考中… N 字 · Ts」,首个正文到达后收成「▸ 已思考 …」可点开看末尾约 200 字。思考文本绝不进译文。
3. **首批 1 块**(< 150 字补到 2 块,≤ 300 字)单独先发;后续 ≤ 10 块 / 2000 字(CJK→拉丁 1250);默认顺序,可选并发 2–3(Ollama 恒 1)。
4. 流式请求加 `Accept-Encoding: identity`。
5. **进行中**:快捷窗状态栏与主窗工具栏显示彩色呼吸点 + 阶段(连接 / 思考 / 生成)+ 运行计时 + 生成阶段实时 tok/s;当前流式块浅强调底 + 闪烁光标;其余显示「还有 N 块待译」。
6. **结束后**:状态栏一行「首字 x.xs · 总耗时 · 输出 tok ⓘ」;ⓘ 弹出明细:连接 / 思考 / 生成分段时间条、TTFT、首块、输入 / 输出(含思考 tok)、生成速度、估算成本、模型 · 块数 · 批数;主窗检查器同一份明细。思考占比高时提示「关闭思考可加快首字」。
7. **用量页**:月汇总(请求 / token / 估算成本)+ 各模型首字中位数(最近 20 次)+ 最近 20 次请求表(时间 / 模型 / 首字 / 总耗时 / 输入输出 / 思考 tok),首字按 < 1s 快 · 1–3s 一般 · > 3s 慢着色。
8. **口径**:TTFT = 首个正文 token − 请求发出;首块 = 首个完整块;速度 = 正文输出 tok /(结束 − 首正文 token)。埋点:provider 层 headers / 首字节 / 首 reasoning / 首 content,translate 层首 partial / 首 block。`usage_log` 增 `ttft_ms, first_block_ms, first_byte_ms, reasoning_tokens, batch_blocks, batch_chars`。

**验收**:关思考可用的预设上 TTFT 中位 ≤ 1.0s、首块 ≤ 1.5s(参考旧实测 deepseek-chat 首 token ~0.7s / 首块 ~0.9s;v0.3 基线待 §6 补测);连接后 300ms 内必有可见变化(阶段点或思考进度);每次翻译结束均可查看完整明细。
— 工单 [05](issues/05-streaming-latency-research.md)、[06](issues/06-metrics-display.md)

### 2.7 整体视觉:macOS 原生

**根因**(审计 高 14 / 中 24 / 低 50):实现与 v4 稿漂移(实现暗色、稿亮色);调试文案外露;译文粗衬线单字重;标题与品牌字体偏离;对照原文与暗色 accent 按钮对比度 2.3–2.7:1;主窗胶囊缺主按钮且空态仍显示;新建页压红绿灯;设置抽屉遮挡胶囊、6 个分区且全是带框输入;阅读背景只铺正文区形成色带;不跟随系统亮暗。

**方案**(原型 `proto-visual/index.html?variant=C`,token 表见 `research/12-visual-language.md`):
1. **视觉语言**:系统材质(半透明)、SF 字体、统一工具栏 + 分段控件、弹出按钮、系统设置式分组列表;**跟随系统亮暗**(外观三态:跟随 / 浅 / 深)与**系统强调色**。
2. **字体**:界面与译文均系统无衬线(译文 500);删除打包的 Source Serif 4。字号阶梯 11 / 12 / 13 / 14.5 / 15 / 17 / 22 / 28,最小 11。
3. **颜色**:语义 token 对齐 macOS label 体系;正文 ≥ 7:1、次要 ≥ 4.5:1;只用「材质 + 文档实底」两种面;禁用态灰底而非半透明 accent;代码块随亮暗。
4. **快捷窗**:统一工具栏(红绿灯 + 译文|对照|原文 + 置顶 / 复制)、弹出按钮行(方向、模型)、源文一行摘要、文档实底译文区、状态栏(指标 + 复制 + 存入文章库)。
5. **主窗**:统一工具栏(对照|分栏|译文、标题、精简进度、☰ ⓘ ⚙);文章库 = 原生侧栏,默认收起(☰ / ⌘K);检查器(进度 / 指标 / 术语命中)默认收起(ⓘ / ⌘I),收起时工具栏常驻精简进度 + 首字;**取消底部悬浮胶囊**。
6. **设置**:独立窗口(⌘,),左侧 4 分区:模型 / 翻译 / 快捷窗 / 用量。
7. **信息密度**:界面常驻区不放快捷键提示 chip(只在菜单 / tooltip / 设置);无调试文案。
8. **动效**:侧栏 / 检查器 200ms ease-out;流式光标 1s 闪烁;无弹跳。
9. **实现路径**(工单 13):Tauri 内置 `windowEffects`(主窗 / 设置 `sidebar`、快捷窗 `popover`;2.12.1+ 免 `macOSPrivateApi`,配置放 `tauri.macos.conf.json`);body 透明、文档区实底;强调色由 Rust 读 `NSColor.controlAccentColor` 发 `accent-changed`(CSS `AccentColor` 在 WKWebView 恒蓝,不用);外观三态由 Rust `set_theme` 统一,删除 localStorage `v3-dark` 与 `theme-changed`;`trafficLightPosition` 对齐 52pt 工具栏;设置窗懒创建 + 关闭即隐藏;自定义应用菜单(⌘, ⌘K ⌘I ⌘L + 外观三态)必须自带「编辑」菜单,并删除 JS 中同名快捷键防双触发。

**验收**:审计 14 项「高」全部消除;亮 / 暗 / 系统强调色切换后三窗即时一致;工具栏内容与红绿灯中线对齐;无文字低于 11pt 或次要对比度低于 4.5:1。
