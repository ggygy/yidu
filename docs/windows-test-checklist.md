# v0.4 划词 / 截图 / 替换 —— Windows 手测清单

> Windows 侧代码(`ocr.rs` WinRT OCR、`selection.rs` UI Automation + SendInput、`capture.rs` 截图工具)
> **在 macOS 开发机上无法编译与运行**,完全依赖 CI 编译 + 本清单人工验证。全部通过后才打正式标签。

## 0. 前置

- [ ] CI `build-windows` 通过(本轮新增 `windows` crate 多个 feature,先确认能编过)
- [ ] 安装 CI 产出的 `yidu_<版本>_x64-setup.exe`,配置好一个可用的翻译模型
- [ ] 设置 → 快捷窗:四个快捷键都显示为已注册(无红字);默认 Alt+T / Alt+D / Alt+S / Alt+R
- [ ] 设置 → 快捷窗:**不出现**「系统权限」分组(Windows 无需授权)

## 1. 划词翻译(Alt+D)

在下列应用里各选中一句英文,按 Alt+D:

- [ ] 记事本(UI Automation 路径)
- [ ] Edge / Chrome 网页正文
- [ ] VS Code 或其他 Electron 应用(多半走模拟 Ctrl+C 兜底)
- [ ] Word

每次检查:

- [ ] 快捷窗出现,原文框是选中的那句,译文开始流式输出
- [ ] 走兜底路径的应用:事先复制一段文字 A,划词翻译后在记事本粘贴,仍是 A(剪贴板已还原)
- [ ] 该条翻译**不在**主窗文章库列表里;点快捷窗右下「存入文章库」后才出现
- [ ] 只选中一个英文单词 → 出现词典卡(音标 / 释义 / 加入生词本),不发模型请求
- [ ] 什么都不选按 Alt+D → 提示「没有取到选中的文本」,不翻译旧内容

## 2. 截图翻译(Alt+S)

- [ ] 按 Alt+S → 系统截图工具的框选界面出现;快捷窗若开着会先让开
- [ ] 框选一段英文 → 快捷窗出现「正在识别图片文字」→ 填入识别文本并翻译
- [ ] 框选一段中文(需系统装了中文 OCR 语言包)→ 识别正确
- [ ] 按 Esc 取消截图 → 不弹任何东西;60 秒内再按 Alt+S 能正常重新开始
- [ ] 未装对应语言包时的报错文案可读(提示去「时间和语言 → 语言」安装光学字符识别)
- [ ] 已知行为:截图会覆盖剪贴板原有内容(截图工具只把结果放剪贴板)
- [ ] 托盘菜单「截图翻译」同样可用

## 3. 粘贴图片

- [ ] 用系统截图(Win+Shift+S)截一段文字,在快捷窗原文框 Ctrl+V → 识别并翻译,且**自动入库**
- [ ] 复制一段普通文字再 Ctrl+V → 行为与以前一致

## 4. 翻译并替换(Alt+R)

- [ ] 记事本里输入一句中文并选中,按 Alt+R → 托盘图标旁短暂显示进行中,选中文字被英文译文替换
- [ ] Ctrl+Z 能撤销回原文
- [ ] 事先复制的文字 A 在替换后仍能粘贴出来
- [ ] 按下 Alt+R 后立刻切到别的窗口 → **不**往别的窗口里粘贴;快捷窗弹出提示「前台应用已切换…译文已复制到剪贴板」
- [ ] 在浏览器输入框、Word 里各试一次

## 5. OCR 引擎 = 多模态模型

- [ ] 设置 → 快捷窗 → 图片文字识别:切到「多模态模型」,选一个支持图片的模型 → 截图翻译正常
- [ ] 选一个**不**支持图片的模型 → 提示「模型识别失败,已改用本机识别」并仍给出结果
